# Client Demo Rehearsal Checklist

## Before the room

- [ ] Target Windows Gate 0 has measured evidence, an accepted
      content-addressed operator attestation, and a recorded pass decision.
- [ ] Frozen git revision, fixture/catalog hashes, versions, prompts, and model
      digest match the release record.
- [ ] Laptop is on power; notifications, updates, VPN, and sleep are controlled.
- [ ] Non-loopback networking is blocked for the strict-offline rehearsal.
- [ ] Power BI Desktop is closed.
- [ ] Last-known-good report and clean reset copy hash correctly.
- [ ] `scripts/reset-demo.ps1` succeeds.
- [ ] Launcher preflight shows Local and compatible without warnings.
- [ ] Model is prewarmed and memory remains within budget.
- [ ] Browser zoom and screen resolution match the recorded setup.

## Full sequence

- [ ] Build prompt produces the exact three-page review plan.
- [ ] Apply emits immediate progress and no gap exceeds five seconds.
- [ ] Report transaction validates and Undo becomes available.
- [ ] West margin question returns the frozen exact bridge and provenance.
- [ ] Add Evidence preview names Margin Drivers and the reserved slot.
- [ ] Apply replaces only that slot and revalidates.
- [ ] +3% scenario answer shows revenue, volume, profit, and elasticity.
- [ ] Scenario is visibly labelled mechanical, not predictive.
- [ ] Open in Power BI unloads Ollama and verifies it is no longer resident.
- [ ] Desktop opens all three pages and the evidence visual correctly.
- [ ] No spoken number differs from the prepared evidence.
- [ ] Undo and reset restore exact known hashes.

## Required repetitions

- [ ] Ten consecutive warm rehearsals pass.
- [ ] Two rehearsals from a cold boot pass.
- [ ] A deliberately invalid binding is rejected and restored.
- [ ] A killed worker is recovered from the journal without duplicate writes.
- [ ] A browser refresh during Apply does not duplicate report objects.

Record every run in `evidence/rehearsals`; do not erase failed attempts.
