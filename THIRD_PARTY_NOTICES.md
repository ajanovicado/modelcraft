# Third-Party Notices

This repository uses Python packages declared in `pyproject.toml`.
Their supplied licenses govern those packages; unresolved provenance is recorded
explicitly below.

The GitHub projects listed in `docs/research/github-reference-brief.md` were
used as architectural and interoperability references. Copied source snapshots
and generated or packaged reference material are recorded below.

The inference-only `powerbi-rag-runtime` 0.1.0 dependency is vendored under
`vendor/powerbi-rag-runtime` as a byte-identical snapshot of the local
`PowerBI-RAG/runtime` package. Its reviewed file hashes and source identity are
recorded in `SOURCE_MANIFEST.json` there. The project owner confirmed ownership
on 2026-10-14 and explicitly licensed the runtime under MIT for public source and
compiled distributions. Its MIT `LICENSE` accompanies the package. See
`OWNER_CONFIRMATION.md` for the owner's statement. No upstream repository revision
was supplied. No model, native binary, experiment or private evidence from the
sibling project is included.

Studio layout templates (`src/ai_powerbi_analyst/studio/layout_templates.json`)
are abstract 12x12 page structures derived from visual positions in dashboards
published in Power BI Design Files by Sajjad Ahmadi (MIT License, Copyright (c)
2024 Sajjad Ahmadi): https://github.com/Dashboard-Design/Power-BI-Design-Files.
No report file, image, icon or theme from that repository is included. The theme
files in that repository belong to other creators (BIBB, Zebra BI, Kerry Kolosko)
and were not used; Studio's report themes were authored for this project.

PBIX imports use PBIXRay 0.15.5 (MIT, Hugoberry / Alphaverse Limited), installed
as a dependency rather than copied source. Its dependencies include xpress8,
xpress9 and xmhuffman for offline VertiPaq decoding. PBIXRay reads model data;
it does not implement Microsoft's native report renderer or full DAX engine.
Upstream: https://github.com/Hugoberry/pbixray

The report editor for imported PBIX files ships a snapshot of Microsoft's public
Power BI report visual catalog (`src/ai_powerbi_analyst/studio/pbir_catalog.json`:
per visual type, the data roles, formatting objects, property types and enum
values). It was generated by `scripts/snapshot_formatting_catalog.py` from
`@microsoft/powerbi-report-authoring-cli` 0.1.4 and its dependency
`@microsoft/powerbi-core-visual-schema` (MIT License, Copyright (c) Microsoft
Corporation), which are used as build-time tools, not bundled. The snapshot
contains property names, types and allowed values only; no Microsoft source code.

Two of Microsoft's public JSON schemas for Power BI report files are packaged in
`src/ai_powerbi_analyst/studio/pbir_schemas/` and used to check every filter the
report editor writes: `filterConfiguration-1.3.0.embedded.json` and
`semanticQuery-1.4.0.json` (MIT License, Copyright (c) Microsoft Corporation).
They are unmodified copies of the files published at
https://developer.microsoft.com/json-schemas/fabric/item/report/definition/
(`filterConfiguration/1.3.0/schema.embedded.json` and `semanticQuery/1.4.0/schema.json`),
stored in this repository's `evidence/report-date-filter-20260920-215429/filter-schemas/`
folder by an earlier session. Validation runs through the `jsonschema` package
(MIT), which is now a declared dependency in `pyproject.toml`.
